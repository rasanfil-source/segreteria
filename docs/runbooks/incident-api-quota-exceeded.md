# API quota exceeded

Operational procedure.

Identify the service, error and quota window. A 429 is not necessarily daily exhaustion. Respect deferral, inspect actual provider quota and local budgets; do not delete counters to force calls. Local daily Gemini accounting uses America/Los_Angeles. Backup keys do not guarantee independent quota.

Retain uncertain-send markers and labels until the outcome is established; follow the full procedure. Check operational behaviour with anonymised examples and offline tests before use.
